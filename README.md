## What Bartube Is

Bartube is a lightweight macOS app that puts YouTube playlist playback in your menu bar.

It is built for people who mainly use YouTube to listen:

- music playlists
- long mixes
- study playlists
- background listening while working

Instead of keeping a YouTube tab open all day, Bartube gives you a cleaner desktop workflow with quick playback controls and a compact native interface.

## Why People Use It

- Keep your browser tabs focused on work
- Start playlist playback quickly from the menu bar
- Keep previous, play, pause, and next controls close by
- See what is playing without switching back to YouTube
- Use your own playlist instead of relying on recommendations

## What You Get

- Native macOS menu bar app
- Background audio playback
- Custom playlist support
- Current track shown in the menu bar
- In-app settings for playlist and API key
- Lightweight interface designed for repeat daily use

## Before You Start

Bartube currently requires:

- macOS 14 or later
- A YouTube Data API key

This key is used so the app can load playlist information from YouTube.

## Setup

1. Download and unzip `Bartube.zip`.
2. Move `Bartube.app` into your `Applications` folder.
3. Launch Bartube.
4. Open the app from the menu bar.
5. Go to `Settings`.
6. Paste your YouTube Data API key.
7. Optionally paste your own playlist ID.
8. Start playback.

## How To Use Your Own Playlist

If you already have a YouTube playlist you use every day:

1. Open the playlist in YouTube.
2. Copy the value after `list=` from the URL.
3. Paste that value into `Settings > Custom Playlist ID`.

Bartube will use that playlist as your default source.

## Who This Is For

Bartube is a good fit if you:

- listen to YouTube more than you watch it
- want fewer browser tabs open
- prefer a native Mac utility over a full website
- return to the same playlists often

It is probably not the right tool if you want the full YouTube browsing experience inside the app.

## Support

If you run into issues, the most common things to check are:

- your YouTube API key is valid
- your playlist ID is correct
- your Mac is running a supported macOS version

## Notes

- Bartube is designed around playlists and listening
- Availability depends on YouTube and your API setup
- This build is intended for direct download and manual installation
